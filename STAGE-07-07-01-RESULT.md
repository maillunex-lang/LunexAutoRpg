# 7.7.1 — Результат реализации (ожидает приёмки)

Дата: 23.11.2026. Основание: CLASS-077 A, COMBAT-077 A, SKILLS-077 B, GITHUB-077 A, LEGACY-077 B.

## Реализовано
- Четыре редактируемых Resource-класса: `warrior`, `mage`, `priest`, `bard`; `LunexClassDefinition` с ID, названием, ролью, базовыми HP/уроном/частотой атаки, иконкой и списком ID способностей.
- SQLite-миграция `profiles.class_id TEXT NOT NULL DEFAULT 'warrior'` в транзакции `BEGIN IMMEDIATE`, с `PRAGMA table_info`, проверкой обязательных старых колонок, идемпотентностью и откатом ошибки.
- **LEGACY-077 B:** все старые профили без класса получают `warrior`, новые тоже `warrior` по умолчанию. Если класс уже установлен, повторная миграция его не перезаписывает.
- `read_profile()` возвращает `class_id` вместе с прежними данными; whitelist из четырёх ID; подготовлен серверный метод назначения класса (пока нигде не вызывается).
- **Боевая логика не изменена:** старые значения HP/урона остаются в `NetworkPlayer`; класс пока только сохранённые данные, не меняет бой. Экран выбора класса, способности, баффы, манапул и система уровней не реализованы. Это задачи 7.7.2+.
