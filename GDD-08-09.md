# GDD-08.9 - Ежедневные активности, достижения и рейтинги

**ЧЕРНОВИК НА СОГЛАСОВАНИЕ 23.11.2026.** GDD-08.8 утверждён. Только проектирование, без внедрения.

## Цель
Связать прокачку без дневных ограничений, сюжет, боссы, кооператив и гильдии в понятный ежедневный игровой цикл, не заставляя игрока проводить часы в обязательных заданиях. Учитывать разные часовые пояса и стабильный серверный сброс.

## Решения на выбор
- **DAILY-089:** A только ежедневные задания; **B ежедневные + еженедельные задачи с гибким набором активностей** (рекомендация); C только сезонные задания.
- **ACHIEVE-089:** A достижения только с косметическими значками; **B достижения с косметикой, титулами и небольшими ресурсными наградами** (рекомендация); C достижения с сильными боевыми бонусами.
- **RANK-089:** A только общий рейтинг GS; **B отдельные рейтинги GS, боссов и гильдий** (рекомендация); C рейтинги всех возможных характеристик и активностей.
- **RESET-089:** A индивидуальный сброс через 24 часа; **B единый серверный сброс с отображением таймера и времени игрока** (рекомендация); C случайное обновление задач.
- **CATCHUP-089:** A пропущенные награды исчезают; **B мягкий догоняющий механизм для части еженедельных задач** (рекомендация); C полная автоматическая выдача пропущенных наград.

## Принципы безопасности и баланса
Прогресс задач, достижений и рейтингов рассчитывается сервером из подтверждённых игровых событий. Отдельно определить точный часовой пояс сброса, лимиты, антифарм, сезонность и правила наград. Не вводить скрытые дневные лимиты уровня вопреки LEVEL-084 A. Публичные рейтинги показывают игровые никнеймы, не персональные данные.

## Godot-редактируемость
Проектные `.tscn`: DailyActivitiesPanel, WeeklyGoalsPanel, AchievementsPanel, LeaderboardPanel, ActivityRewardPopup. `.tres`: ActivityDefinition, AchievementDefinition, LeaderboardCategoryDefinition, RewardDefinition. Редактируемые визуальные компоненты, темы, иконки, расположение, анимации и тексты в Godot 4.7.2 на ПК. Серверная проверка и награды остаются авторитетными.
