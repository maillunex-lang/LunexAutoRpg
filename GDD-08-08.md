# GDD-08.8 - Гильдии и совместное развитие

**ЧЕРНОВИК, ожидает выбора владельца, 23.11.2026.** GDD-08.7 утверждён. На данном этапе только проектирование, без установки кандидатов или изменения игры.

## Цель
Добавить долгосрочную социальную цель поверх групп до 5 игроков: гильдии, совместные задания и боссы, прогресс гильдии и понятные награды. Референс игрового цикла Era of Celestials, но собственный мир и ассеты.

## Варианты для утверждения
- **GUILD-088:** A небольшие гильдии до 20 игроков; **B гильдии до 50 игроков** (рекомендация); C большие гильдии до 100+ игроков.
- **RANK-088:** A только лидер и участники; **B лидер, офицеры и участники с настраиваемыми правами** (рекомендация); C сложная многоуровневая иерархия.
- **ACTIVITY-088:** A только общий чат; **B задания гильдии, совместные боссы и еженедельные цели** (рекомендация); C сразу полномасштабные гильдейские войны.
- **PROGRESS-088:** A без прокачки гильдии; **B общий опыт/уровень гильдии и разблокируемые бонусы без резкого дисбаланса** (рекомендация); C постоянные сильные бонусы, обязательные для конкурентоспособности.
- **JOIN-088:** A вступление только по приглашению; **B заявки, приглашения и открытый набор с фильтрами** (рекомендация); C автоматическое распределение по гильдиям.

## Правила экономики и безопасности
Сервер проверяет членство, роли, вклады, ежедневные/еженедельные задачи, персональные награды и права на управление. Антиспам, аудит переводов полномочий, ограничения мультиаккаунтов и защита от злоупотреблений. Не делать гильдию обязательной для прохождения основной сюжетной линии.

## Редактирование через Godot
Проектные будущие `.tscn`: GuildHome, GuildMembers, GuildApplications, GuildTasks, GuildBossPanel, GuildProgress; `.tres` ресурсы описания наград/уровней/прав. Все экраны, элементы, темы, анимации, иконки и визуальные сцены редактируются в Godot на ПК; авторитетные данные и проверки остаются серверными.
