# GDD-08.11 - Питомцы, спутники и помощники

**ЧЕРНОВИК, ожидает утверждения владельца, 23.11.2026.** GDD-08.10 утверждён. Только проектирование, без внедрения.

## Концепция
Спутники помогают в сражениях, дают дополнительные цели коллекционирования и прогрессии, но не заменяют роли игроков (танк, ДД, хил, саппорт) и не должны быть обязательными для прохождения сюжета. Все визуальные сущности редактируются через Godot 4.7.2.

## Варианты
- **PET-0811:** A только декоративные питомцы; **B боевые питомцы с ограниченной поддержкой** (рекомендация); C полноценный второй управляемый персонаж.
- **ACQUIRE-0811:** A только покупка у NPC; **B квесты, боссы, события и изготовление** (рекомендация); C только случайные призы.
- **ROLE-0811:** A питомцы наносят только урон; **B атака, защита, лечение и поддержка с ограничениями** (рекомендация); C питомец полностью повторяет класс игрока.
- **PROGRESS-0811:** A без развития; **B уровни, ранги и 1–2 активных умения с понятным пределом силы** (рекомендация); C сложное древо талантов с десятками узлов.
- **CONTROL-0811:** A полностью ручное управление; **B автоматическое поведение + одна ручная команда** (рекомендация); C исключительно автономный AI без контроля игрока.

## Архитектура и баланс
Сервер управляет призывом, характеристиками, действиями, кулдаунами, наградами и сохранением питомца. Не давать питомцам обходить ограничения наград или анти-AFK; поддерживать восстановление после реконнекта. На слабых Android применять LOD, ограничения VFX и анимаций. Платные/гача механики не утверждены.

## Godot-редактируемость
Проектные `.tscn`: PetCompanion3D, PetCollectionPanel, PetUpgradePanel, PetCommandButton; `.tres`: PetDefinition, PetSkillDefinition, PetGrowthDefinition. Внешний вид, модели, анимации, точки крепления, VFX, UI и иконки должны редактироваться через редактор Godot 4.7.2 на ПК. Серверная логика остаётся авторитетной.
