GitHub REST API на VPS ответил rate limit 403, поэтому метаданные и содержимое четвёртой лицензии не были независимо подтверждены. Для официальных демонстраций нельзя автоматически считать все медиа-ассеты свободными от отдельных условий. `git ls-remote` **не является** проверкой сборки, GDExtension ABI или Android.

## План дальнейшей совместимости (без интеграции)
1. Получить pinned checkout или архивы всех четырёх кандидатов в отдельный временный каталог только после разрешения на TEST.
2. Проверить `project.godot`, `plugin.cfg`, `*.gdextension`, платформенные `.so/.dll/.dylib`, лицензии и asset-licenses.
3. Для GH77-002 собрать отдельный минимальный Godot 4.7.2 стенд, запустить headless и Android export, при необходимости проверить ARM64 и GDExtension. Отчёт с фактическими ошибками.
4. Для GH77-001/003 ограничиться чтением/архитектурным сравнением (STUDY).
5. Для GH77-004 выбрать конкретную сцену/скрипт, проверить лицензии и предложить точечный перенос на отдельное утверждение.
6. Отдельно подтвердить любые изменения зависимостей и только затем начинать реализацию.

## Рекомендация
Основной серверный расчёт и хранение класса оставить собственной компактной GDScript/SQLite системой; внешние проекты применять как источники идей или изолированные примеры. Избегать непроверенных Android GDExtension зависимостей.
