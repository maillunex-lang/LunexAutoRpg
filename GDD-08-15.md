# GDD-08.15 - Управление, автопрохождение и навигация на Android

**ЧЕРНОВИК НА СОГЛАСОВАНИЕ 23.11.2026.** GDD-08.14 утверждён. Только проектирование, без внедрения.

## Цель
Сделать удобное горизонтальное управление на Android с 6 ГБ RAM, понятную навигацию по пяти зонам Пепельной долины, поддержать ручную игру и авто-режим без автоматической победы над сложными механиками.

## Варианты для утверждения
- **MOVE-0815:** A только виртуальный джойстик; **B виртуальный джойстик + тап для перемещения/автопути** (рекомендация); C только тап по земле.
- **AUTO-0815:** A только автоатака; **B автоатака, автоподход и автонавигация к квесту с ручным вмешательством** (рекомендация); C полное автоматическое прохождение всех механик, включая рейды и PvP.
- **QUESTNAV-0815:** A только маркеры на миникарте; **B нажатие на задачу строит маршрут к NPC/цели с корректным обходом препятствий** (рекомендация); C мгновенная телепортация к любой задаче.
- **HUD-0815:** A фиксированный HUD; **B редактируемые расположение и масштаб кнопок с пресетами** (рекомендация); C полностью скрытый HUD без подсказок.
- **AUTOSAFETY-0815:** A автоматизация действует всегда; **B авто-режим отключается/ограничивается в PvP, сложных фазах боссов и опасных ситуациях** (рекомендация); C авто-режим разрешён только в городе.

## Архитектура и ограничения
Сервер авторитетен для движения, дистанций, боевых действий, целей, маршрутов, квестовых флагов и наград. Клиентское pathfinding-предсказание допустимо лишь с проверкой сервером. Авто-режим не должен обходить анти-AFK, механики рейдов, арены и ограничения наград. Кнопки и их сохранённые позиции не должны выходить за safe-area. Поддержать Android Compatibility и тесты на слабых устройствах.

## Godot-редактируемость
Проектные `.tscn`: MobileJoystick, TapMoveMarker, QuestNavigator, AutoModePanel, HudLayoutEditor, MinimapPanel; `.tres`: ControlPresetDefinition, AutoModeRulesDefinition, HudLayoutPreset. Визуал, иконки, шрифты, расположение, размеры, сцены, камера, навигационные зоны и пути редактируются в Godot 4.7.2 на ПК. Сохранение персональной раскладки отдельно от канонического дизайна.
