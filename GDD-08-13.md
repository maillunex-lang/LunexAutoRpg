# GDD-08.13 - Подземелья, рейды и PvE-испытания

**УТВЕРЖДЕНО владельцем 23.11.2026:** DUNGEON-0813 B, PARTY-0813 B, DIFFICULTY-0813 B, RAID-0813 B, LOCKOUT-0813 B.

## Канонические решения
- **DUNGEON-0813 B:** сюжетные и повторяемые подземелья.
- **PARTY-0813 B:** часть подземелий доступна соло; сложные рассчитаны на группу до пяти игроков, без требования обязательной группы для основного сюжета.
- **DIFFICULTY-0813 B:** обычная, героическая и испытание с читаемыми модификаторами.
- **RAID-0813 B:** отдельные рейдовые боссы для двух групп по пять игроков (всего десять); обычный лимит группы пять не меняется.
- **LOCKOUT-0813 B:** повторное прохождение доступно, но ценная добыча имеет персональные лимиты, согласованные с RESPAWN-086 B.

## Архитектура
Сервер авторитетен для входа, состава, инстансов, фаз боссов, сложности, наград, ограничений, реконнекта, анти-AFK и защиты от дублирования. Две группы рейда имеют отдельный raid-roster; права и взаимодействие требуют отдельной детализации. Оптимизация Android с 6 ГБ RAM обязательна.

## Редактируемость Godot
Проектные `.tscn`: DungeonEntrance, DungeonLevel3D, DungeonHud, DungeonResultsPanel, RaidBossArena, RaidRosterPanel; `.tres`: DungeonDefinition, DungeonDifficultyDefinition, RaidDefinition, DungeonRewardDefinition. Локации, окружение, боссы, камеры, VFX, UI и анимации редактируются через Godot 4.7.2 на ПК. Реализация не начата.
