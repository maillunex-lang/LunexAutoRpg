# GDD-08.6 - Мировые и групповые боссы

**ЧЕРНОВИК НА УТВЕРЖДЕНИЕ, 23.11.2026.** GDD-08.5 принят. На этом этапе только проектирование и исследование GitHub.

## Концепция
В «Пепельной долине» боссы становятся регулярными совместными событиями в духе Era of Celestials: видно появление босса, игроки могут прийти на помощь, бой состоит из читаемых фаз, каждый квалифицированный участник получает персональный дроп. Воины держат агрессию, маги наносят урон, жрецы лечат, барды усиливают и поддерживают.

## Предлагаемые решения (ещё не утверждены)
- **WORLD-086**: A фиксированное расписание мировых боссов; **B** расписание плюс события появления по активности игроков (рекомендация); C только случайные появления.
- **INSTANCE-086**: A общий открытый мир для всех; **B** мировой босс в открытом мире + отдельные групповые инстансы (рекомендация); C все боссы в инстансах.
- **PHASE-086**: A одна фаза; **B** 2–3 фазы с предупреждаемыми атаками и изменением механик (рекомендация); C 4+ сложных фаз.
- **SCALING-086**: A фиксированная сила; **B** ограниченное масштабирование HP/урона по числу активных участников с верхним пределом (рекомендация); C неограниченное масштабирование.
- **RESPAWN-086**: A бесконечные попытки без ограничений; **B** личные лимиты на ценные награды, но возможность помогать другим (рекомендация); C полный запрет повторных боёв после получения награды.

## Роли и сервер
- Сервер считает агрессию, движение, фазы, телеграфы атак, урон, лечение и полезные эффекты.
- Защита от AFK, автокликеров, повторной выдачи, эксплойтов с выходом из группы; вклад рассчитывается в нормированных значениях по ролям.
- При реконнекте возвращать состояние босса и личную историю участия.
- Для слабых Android ограничивать отображаемые эффекты, имена и модели других игроков без нарушения серверного боя.
