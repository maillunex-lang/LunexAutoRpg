# CONTENT-02: приёмка сюжетного MVP

Дата: 23.11.2026. Статус: **DONE (MVP)**, не общий Content Complete 1.0.

## Реализовано

- 11 сюжетных заданий по пяти зонам, связная цепь с серверной проверкой предпосылок и наград.
- 3 дополнительных побочных задания, выдача награды один раз, персистентность SQLite.
- 8 NPC-диалогов в редактируемых Godot `.tres`, диалоговые и квестовые кнопки как `.tscn`.
- История и цель в журнале, путь к NPC-выдавателю задания, включая последовательный переход через зоны.
- Редактируемая финальная сцена `.tscn`, кнопка пропуска, защита от повторного воспроизведения при reconnect.

## Проверки

- `stage837_story_editor_assets`: PASS, 8 диалогов, 11 сюжетных задач, журнал.
- `stage838_story_enet_client`: PASS, реальный ENet-клиент получил серверный маршрут к Наставнику.
- `stage839_story_enet_quest`: PASS, сервер отклонил попытку принять финальное задание до выполнения предыдущих.
- `stage840_content_story_multizone`: PASS, серверный маршрут к NPC через зоны 1→2→3→4.
- `stage841_story_finale_scene`: PASS, финальная сцена, пропуск, отсутствие повторного показа при входе.
- `stage842_sidequest_authority`: PASS, три определения, prerequisite, награда один раз.
- `stage843_story_server_runner` + `stage843_story_client_runner`: PASS, настоящий ENet UDP 28995, последовательные 11/11 заданий, 500 опыта, 3 предмета, серверное сохранение SQLite. Для ускорения автоматического прохождения серверный тестовый runner перемещал игрока к целям и усиливал его характеристики. Это **не** ручное прохождение на Android и **не** проверка баланса/обычного перемещения.
